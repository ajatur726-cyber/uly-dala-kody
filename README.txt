ZIP-ті ашыңыз. Ішіндегі файлдар мен assets қалтасын GitHub репозиторийінің түбіріне бірге жүктеңіз. ZIP файлының өзін жүктемеңіз.

Егер сайт файлдарын өңдейтін терезеде Commit failed қатесі шықса, репозиторийдің Code → Add file → Upload files бетін пайдаланыңыз.

Файлдарды екі ретпен жүктеуге болады: алдымен HTML, DOCX және PDF файлдарын; кейін assets қалтасын. Әр жүктеуді Commit changes арқылы сақтаңыз.

Settings → Pages → main → /(root).
