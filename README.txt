Бұл нұсқада assets немесе сынып қалталары қажет емес. Барлық HTML файлдары жеке жұмыс істейді.

1. ZIP-ті компьютерде ашыңыз.
2. GitHub → Code → Add file → Upload files арқылы архив ішіндегі БАРЛЫҚ файлды бірге жүктеңіз.
3. Commit changes басыңыз.
4. Pages жариялауы аяқталған соң Ctrl+F5 басыңыз.

index.html, tarbie.html, kauipsizdik.html, normativ.html және барлық tarbie-grade-*, safety-grade-* файлдары бір деңгейде тұруы керек.
Браузерде жергілікті тексеру үшін index.html файлын ашыңыз.
Сыртқы құжаттар мен бейнелерге интернет қажет.
